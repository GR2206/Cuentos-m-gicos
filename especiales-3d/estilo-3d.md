# Estilo 3D — bloques fijos de prompt

Cada prompt de escena se arma así: **[ESTILO] + [PERSONAJE] + [LUGAR] + acción y cámara + [CIERRE]**.
Copiá los bloques sin cambiarlos: así todas las escenas se ven iguales.

## [ESTILO]
```
3D animated children's cartoon, soft velvety plush fur like a high-quality stuffed toy, rounded chunky shapes, big glossy eyes, warm gentle lighting, soft shadows, cozy saturated but soft colors, shallow depth of field, slow gentle movements, calm and sweet mood for toddlers.
```

## [CIERRE] (va al final de TODOS los prompts)
```
Keep the main character centered in the frame. No music, no voices, no speech, no singing, no text, no subtitles, no logos, no watermark. Only soft natural ambient sounds.
```

## Trucos aprendidos
- **Luciérnagas:** pedirlas como `small round glowing light dots floating in the air, not bees, no insects`. Si no, salen abejas.
- Siempre **x1** (no x2) para no gastar el doble de créditos.
- Una acción simple por escena (8 s no da para más). Si pedís tres cosas, hace dos mal.
- Repetir el **mismo bloque de lugar** en todas las escenas de un especial para que el escenario no cambie.
- Si una escena tiene que empezar exactamente donde terminó la anterior, se puede usar **Frames to Video**
  con el último cuadro del clip anterior (yo te lo saco del video).
- Pedir **sin texto**: los títulos y subtítulos los pongo yo después, con la tipografía del canal.
